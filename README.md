# DELVERS（仮題）

冒険者を派遣し、帰ってきた未鑑定品を開ける放置型ハクスラの MVP。
**プレイヤーは戦闘を一切見ない。** 出撃前に3つの判断——装備・撤退ルール・派遣先——を
するだけで、あとはアプリを閉じてよい。

## ゲームループ

```
【拠点】 帰還レポート確認 → 未鑑定品を一括開封 → インベントリ整理
        → 武器1+防具1を装備 → 撤退ルール → 派遣先 → 派遣
   ↓ アプリを閉じてよい（オフライン進行・上限8時間）
【帰還】 撤退成功／ステージクリア／死亡（戦利品全ロスト＋装備2点消滅）
```

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 静的検査(C2/C6/C9/C11) + 破綻検査(C3/C4/C5/C7/C8/C9)
npm run build      # 型検査 + ビルド

npx tsx test/balance.ts matched   # ステージ相当の装備での到達率
npx tsx test/balance.ts over      # 周回した装備での到達率
npx tsx test/playtest.ts <seed>   # B軸（20回派遣）の手触り検証
```

URL パラメータ:
- `?seed=<hex>` — セーブが無いときの初期シード
- `?reset=1` — セーブを消して開始
- `?timescale=N` — 実時間を N 倍速で進める（**開発時の確認用**。本番は 1）

## アーキテクチャ

```
src/
  sim/     決定論シミュレーション。Canvas/DOM も実時計も参照しない
    prng.ts      xorshift（v1から流用）
    items.ts     装備生成 L0〜L4（§5）
    combat.ts    戦闘の内部ターン制解決（§6）
    offline.ts   オフライン進行。時刻は引数で注入（§7.2）
  data/    ベースタイプ／アフィックス／ユニーク／職／ステージ／遭遇
  render/  描画専用（360×640 内部解像度 → 整数倍スケール、32色パレット）
  ui/      拠点・派遣・インベントリ・開封・レポート・図鑑
  game/    セーブと画面遷移
```

設計の要点:

- **戦闘結果は派遣した瞬間に確定する。** 実時間は「いつ見せるか」だけを決める。
  進捗は開始時刻と観測時刻という2つの絶対時刻からのみ導出するため、8時間を
  一括計算しても1分×480回に分割しても結果が必ず一致する（C4）。
- **端末時刻の巻き戻しでは進行しない。** 観測時刻を据え置くことで進行量ゼロにする（C5）。
- **総ダメージ量は狭くしか揺らさない。** 武器6種は素の DPS がほぼ等価で、
  差は会心率・引けるアフィックス池・「1撃の大きさ vs 手数」が敵防御に対して
  持つ意味で付く。新しい武器が古い武器の単純な上位互換にならないようにするため（§5.1）。
- **数値は5段階のティアでしか見せない。** `+11.3%` と `+11.7%` の差はノイズ（§5.6）。
