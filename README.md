# OUTFITTER（仮題）

装備屋の店主となり、客を読み、装備を見立てて渡し、ダンジョンへ送り出して観戦する
スマートフォン縦持ち向けゲームの MVP。プレイヤーは一度もダンジョンに潜らない。

## 遊び方（1サイクル約100秒）

1. **商談（30秒）** — 客カードを読み、質問を1回だけして、棚から装備を最大3点渡す
2. **見送り（3秒）** — 天秤が成功見込みを暗示する（数値は出ない）
3. **観戦（50〜70秒）** — 縦断面のダンジョンを冒険者が自動降下。約20秒ごとに計3回の選択。
   装備を渡していれば追加の選択肢が開く（根拠の装備アイコン付き）。制限時間5秒
4. **結果（10秒）** — 到達深度・納品・装備の消耗。敗因/成功要因は手紙1行で明示

常連1人を最大6ランまで追う。死亡すると系譜は終了し、遺品を1つ携えた次代が来店する。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 静的検査(C2/C5) + 決定論・破綻検査(C3/C6/C7) + 系譜通し
npm run build      # 型検査 + ビルド
```

URL パラメータ: `?seed=<hex>`（ラン再現） `?auto=1`（自動プレイ） `?fast=N`（再生速度）

## アーキテクチャ

```
src/
  sim/     決定論シミュレーション。Canvas/DOM を一切 import しない
  data/    装備12種・イベント15種・性格3種・戦利品のマスタ
  render/  描画専用（360×640 内部解像度 → 整数倍スケール、ドット絵）
  ui/      商談・観戦・選択・結果・図鑑の各画面
  game/    店・系譜・画面遷移
```

ダンジョン攻略は `simulate(seed, adventurer, equipment[], choices[]) => SimEvent[]`
の決定論シミュレーションで、観戦画面はその再生に徹する。1ランの結果は
seed + 装備ID配列 + 選択履歴（数十バイト）だけで完全再現できる。
