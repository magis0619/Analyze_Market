## 手元での始め方

```sh
git fetch origin claude/game-creation-bcoyzz
git checkout claude/game-creation-bcoyzz
npm install
```

### web 版を動かす・確かめる

```sh
npm run dev            # 開発サーバ
npm test               # 静的検査 + シミュレーション + UI 検証（854 件）
npm run test:ui        # UI 検証だけ（vite build と preview を含む）
```

`npm test` の最後は Playwright が実物のブラウザを開いて 854 件の表明を測る。
Chromium が要る（`npx playwright install chromium`）。

### Swift 版を動かす・確かめる

```sh
cd swift && swift test          # Xcode なら Package.swift を開く
npm run swift:verify            # 移植した論理を照合（Swift を待たずに回せる）
```

どちらも通る状態。`swift test` は 14 件、`swift:verify` は 7,810 件。
落ちたときの読み方は `swift/README.md` の表にある。
