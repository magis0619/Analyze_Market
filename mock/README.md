# three.js モック（検討用）

`src/` の本体には一切手を入れていない。ここは「three.js で描いたらどうなるか」を
見るためだけの使い捨ての試作で、採否が決まるまで本体とは独立している。

## 見かた

```
cd mock && npx vite --port 4190
# http://localhost:4190/?s=base
```

`?s=` で画面を切り替える: `base` / `dispatch` / `report` / `reveal` / `compare` / `inventory`
`?t=6` で時間を固定できる（スクリーンショット用）。

## 構成

| ファイル | 役割 |
|---|---|
| `scenes.js` | three.js の 3D レイヤー。**文字や数値は一切置かない** |
| `screens.js` | HTML の情報レイヤー。読ませるものは全部こちら |
| `style.css` | 見た目。モダンファンタジーの配色と部品 |

3D は「情報を読ませる板の後ろに、奥行きと光を置く」ためだけに使う。
外部テクスチャ・外部モデルは読み込まない（基本形状＋ライティング＋霧＋発光のみ）。

## 現行の仕様との衝突

`docs/SPEC.md` §9 は以下を定めており、この方向は**そのすべてに反する**。

- 描画は「HTML5 Canvas 2D（WebGL は使わない）」
- 内部解像度 360×640・整数倍スケール
- ビットマップフォント（TrueType のアンチエイリアス禁止）
- パレット32色以内
- bloom／ブラー／グラデーションオーバーレイの禁止

採用するなら §9 を丸ごと書き直すことになる。判断は保留中。
