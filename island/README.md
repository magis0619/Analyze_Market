# 島歩き（仮）

綺麗な海に囲まれた島を歩くだけの three.js 製の小品。ゴールも競争もない。
DELVERS（このリポジトリのルート）とは別アプリで、vite の root ごと分けてある。

```bash
npm run island:dev      # http://localhost:5174
npm run island:build    # 型検査 + ビルド（dist-island/）
npm run island:shots    # 画面を一式撮る（要 dev サーバ）
npm run island:critique # 参考画像との色の突き合わせ（要 dev サーバ）
```

URL パラメータ:

| パラメータ | 意味 |
|---|---|
| `view` | `beach` / `overlook` / `shallows` / `reef` と、自己批評用の `rest` / `palms` / `adan` / `deigo` / `mangrove` / `pier` / `lineup` |
| `time` | 0〜24 の時刻 |
| `weather` | 0（快晴）〜1（曇天） |
| `still` | 波と雲の時刻を固定する（スクリーンショットの再現性用） |
| `hud` | `0` で操作パネルを隠す |
| `arrive` | 到着の度合いを 0〜1 で固定する（演出の途中を撮るため） |
| `lineup` | `1` で、種を1体ずつ並べただけの検分用シーンにする |

操作は WASD / 矢印キーで歩き、ドラッグで見回す。`H` でパネルの開閉。
スマホは画面左側のドラッグで移動、右側のドラッグで視点。

## 構成

```
island/src/
  heightfield.ts  湾の地形（4層の高さレイヤーと2つの岬）を CPU で焼く
  terrain.ts      焼いた高さ場 → メッシュ + 水が参照する深度テクスチャ
  water.ts        深度ベースの水シェーダ（吸光・散乱・Gerstner波・泡）
  sky.ts          手続き生成のスカイドームと星
  meshbuild.ts    手続きジオメトリの組み立て（筒・リボン・塊・箱）
  flora.ts        種ごとの植生ジオメトリ（ヤシ／アダン／デイゴ／月桃／
                  マングローブ／ソテツ／花木／汎用の低木と木）
  structures.ts   東屋・ハンモック・桟橋・灯台・琉球石灰岩の石垣・焚き火跡
  foliage.ts      どの種をどこに撒くかと、共通マテリアル
  textures.ts     琉球石灰岩のアルベド／法線マップをその場で焼く
  env.ts          時刻・天候・到着度と、全マテリアルが共有するユニフォーム
  walker.ts       歩行カメラと決め打ちの視点
  glsl/           空・深度サンプリングの共通シェーダチャンク
```

外部アセットはひとつも持たない。岩肌のテクスチャも星も地形も、
すべてシード付きの決定論ノイズからその場で生成している。

## 見た目をどう決めたか

指示書の「参考画像に一致させる」を目分量でやらないために、
**画面を縦20帯に割って帯ごとの平均色を出し、参考画像の実測値と突き合わせる**
方法を採った（`scripts/critique.mjs`）。数値で外れているところだけを直す。

主要な色は sRGB の16進で決めてシェーダ内で線形に直している
（`sRGB()`）。トーンマッピングは `NoToneMapping`。
指定した色がそのまま画面に出ないと、突き合わせが意味を持たなくなるため。

### 水（指示書 §2）

海面の色は「海底までの深さ」ひとつから導いている。

```
body = 海底の色 × exp(-吸光係数 × 光路)      … 透過して見える砂・珊瑚
     + 散乱係数/(2×吸光) × (1 - exp(-2×吸光×深さ))  … 水そのものの色
```

赤がいちばん早く失われるので、浅い＝白砂の色、深い＝ターコイズ、
さらに深い＝紺、という参考画像どおりのグラデーションが自動的に出る。
吸光・散乱の係数は、参考画像の帯ごとの実測色から逆算した値を使っている。

水面の映り込みは素の Fresnel をそのまま使うと、斜めから見た浅瀬が
一面の空色になってしまう。参考画像はいずれも PL フィルタ越しの写真で
反射が大きく削られている（だから珊瑚が透けて見える）ので、
手前ほど反射率を落とし、水平線に近づくほど本来の値に戻している。

### 地形（指示書 §1）

放射ノイズだけでは入り江の抱擁感が出ないため、2つの岬をスパイン
（制御点の折れ線）で明示的に置き、その間を遠浅の水域にしている。
海底は3段構え。汀線の2mはごく浅く（寄せ波が砂の上を走る余地）、
そこから15mほどは浜の急な面、その先が遠浅の棚。
砂を離れるとすぐターコイズが濃くなり、かつ湾いっぱいが明るい、
という参考画像の両方を満たすための形。

### 空（指示書 §3）

密度勾配（地平線ほど大気が厚い）・光度勾配（太陽方向への近さ)・
トワイライト（その積）の3つを掛け合わせる。時刻 0〜24 のパラメータ
ひとつで夜明けから夜まで回る。同じ関数を水面の反射と大気遠近でも
使うので、水平線が破綻しない。

夜は主光源が太陽から月に切り替わる（`uKeyDir` / `uKeyLight`）。

### 天候

個別のシステムは作らず、彩度を落とす・フォグ密度を上げる・
雲量を上げる・太陽の光度を弱める、の4つだけ（指示書 §3 の方針）。

### 到着と、帰り道（想定プレイヤー像）

指示書の「仕事に疲れて南国に行っている人」という前提を、雰囲気ではなく
判断基準として扱っている。

- **到着の演出** — 起動直後は彩度を落とした青灰色（オフィスの残響）から
  始まり、6.5 秒かけて光と彩度が満ちる。`uArrive` ひとつを全マテリアルの
  `grade()` に通しているだけなので、あとから足した要素も自動でこの演出に乗る。
- **終わり方** — タブを離れる／ウィンドウのフォーカスが外れると、
  2.8 秒かけて静かに彩度が引く。戻ればまた満ちる。「行って、帰ってくる」
  をひとつの体験にするため、帰り道のほうを少し速くしてある。
- **数字を見せない** — 時刻は `11:30` ではなく「真昼」「夕焼け」と出す。
  スコアもカウンターも進捗率も無い。到着度も内部の値のままで UI には出さない。
- **急かさない** — タイマー・通知・誘導は一切無い。何もしなくても何も減らない。

### 植生と人工物（指示書 §4-1）

種ごとにシルエットが違うことが大事なので、汎用の「木」を色替えするのでは
なく、それぞれの特徴を形で作っている。置き場所も表のとおりに分けた。

| 種 | 形の要点 | 置き場所 |
|---|---|---|
| ヤシ | しなる幹と、垂れる羽状葉。variant 3種で幹の曲がりと垂れ方を変える | 砂浜沿い（汀線から 5〜38m） |
| アダン | 放射状の太い帯状葉と、幹から地面へ降りる気根 | 岬の岩場のふち（傾斜 0.22 以上） |
| デイゴ | 広く張った枝先に、真っ赤な房 | 岬に2本だけ |
| 月桃 | 笹に似た幅の広い葉の株と、垂れ下がる白〜桃の花穂 | 東屋の足元 |
| マングローブ | 絡み合って水面から突き出す支柱根 | 湾の奥、波の当たらない浅い隅 |
| ソテツ | 葉痕の残る太い幹に、垂れない硬い羽状葉 | 東屋・桟橋まわり |
| ハイビスカス／ブーゲンビリア | 葉の面より外に出した花 | 東屋・桟橋まわり |

人工物は東屋・ハンモック・焚き火跡・桟橋・灯台・石垣。数は少なく、
「人の手が入った気配」だけを置いている。

羽状葉（ヤシとソテツ）は同じ関数で作っていて、芯まわりの角度 `phi` を
大きくすると垂れてヤシに、小さいままだと硬く跳ねてソテツになる。

見比べは `?lineup=1` が早い。種を1体ずつ砂の上に並べたシーンになる。

## 残っている差

`npm run island:critique`（砂浜視点・11:30・快晴）の実測:

| 領域 | 平均色差 |
|---|---|
| 空 | 16.3 |
| 海 | 31.0 |
| 砂浜 | 18.4 |
| 全体 | 21.2 |

残っている差は主に2か所。

- **水平線ぎわ（画面 40〜45%）** — 参考画像はここに巻雲が横切っていて、
  雲量ひとつでは同じ位置に同じ雲を置けない。
- **汀線から数 m（画面 60〜70%）** — 参考画像のこの位置の色は水深 1m 相当だが、
  目線 1.7m から見るとその画面位置は汀線の 1〜4m 沖にあたる。
  そこに水深 1m を持たせるには汀線を崖にするしかなく、寄せ波が
  砂を走る余地が無くなる。ここは physically ありえる形のほうを採った。

なお、赤の吸光係数は実際の海水（0.45/m 程度）よりかなり大きい値を使っている。
参考画像はいずれも彩度を上げた写真で、浅瀬から赤が完全に抜けているため。

## 次にやること（指示書 §5 の続き）

波が足跡を消す／漂着物拾い／瓶に手紙を流す／潮の満ち引きで現れる道。
足跡と漂着物は、すでにある「寄せ波の水面高さ」（`swash()`）と
深度テクスチャの上に乗せられる。
